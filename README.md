# Exam Topic Prioritizer

## 📌 Project Description

Exam Topic Prioritizer is a Java Swing based student study management application. It helps students prioritize exam topics based on marks, difficulty, and preparation level.

## 🚀 Features

- Student Login
- Dashboard
- Topic Management
- Topic Prioritization
- Study Timer
- Practice Questions
- Progress Tracking
- Exam Date Tracking
- Study Settings

## 🛠️ Technologies Used

- Java
- Java Swing
- Java AWT
- ArrayList
- Java Time API

## 🧠 DSA Used

- ArrayList
- Arrays
- Stack concept
- Queue concept
- Graph algorithms in study content
